workflow
1. user enter prompt. "lets build an shopify app"
2. clarify user by asking what kind of app?
3. create a project json file .devcom/project.json - this will store credentials such app version, shopify partner, backend credentials of choice (Fly.io, Render, Railway,
Heroku, or a VM), and others.
4. make sure all required files, documents, or assets are generated.
5. implement install action
6. integrate github to connect to repository.
